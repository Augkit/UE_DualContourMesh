# DualContourMesh

一个基于 **Unreal Engine 5** 的实时可破坏地形实验插件。

项目使用体素数据描述地形，并通过 **Dual Contouring** 动态重建网格，使地形在被挖掘、切削、平滑和破坏后，仍能生成相对平滑、同时保留一定锐边特征的表面。

整体方向受到任天堂在《**Donkey Kong Bananza / 咚奇刚 蕉力全开**》公开介绍的可破坏地形技术启发：用 **Voxel** 表示地形，并让体素承载几何之外的附加信息。当前这套实现中，核心体素数据主要围绕 **密度** 与 **材质 ID** 展开，用于驱动地形重建、编辑和材质混合。

## 项目说明

`DualContourMesh` 是一套面向 Unreal Engine 的体素地形实验插件。它包含运行时模块与编辑器模块，既能在场景中生成和更新可破坏地形，也提供了对应的编辑、预览和笔刷工作流。

项目包含了：

- 使用体素密度场保存地形形状。
- 使用 Dual Contouring 将体素数据重建为可渲染网格。
- 支持分块生成与局部更新，以适应实时编辑场景。
- 支持材质混合、笔刷雕刻和平滑等交互式地形修改。
- 支持将外部体积数据采样到体素地形中，例如 Sparse Volume Texture。

## 实现原理

项目的核心思路可以概括为三步。

### 1. 用体素存储地形

地形并不是直接以静态网格保存，而是先存成一个三维体素场。每个采样点记录密度信息，部分数据还会记录材质 ID。这样做的好处是，地形修改首先发生在体素层，便于执行挖掘、填充、平滑、布尔操作和材质涂抹。

### 2. 用 Dual Contouring 重建表面

当体素密度发生变化后，系统会在受影响区域内重新计算表面，并通过 Dual Contouring 生成新的网格。相比简单的体素立方体拼接，这种方法能得到更平滑的表面，同时在一定程度上保留棱边和硬表面结构，更适合表现“可破坏但不完全方块化”的地形效果。

### 3. 用分块更新支持实时编辑

为了避免每次编辑都重建整块地形，项目会把地形划分为多个区域，只更新受影响的部分。当前实现还包含异步构建和分帧应用逻辑，用来降低大范围修改时的卡顿风险。这也是它能够用于实时雕刻、破坏和运行时修改的基础。

## 当前特性

- 实时可破坏体素地形
- 基于 Dual Contouring 的动态网格重建
- 分块生成与局部更新
- 地形雕刻、挖掘、平滑与材质绘制
- 基于 Volume Sampler 的体积编辑流程
- 从 Sparse Volume Texture 采样生成体素地形
- Unreal Editor 中的预览与编辑工具链
